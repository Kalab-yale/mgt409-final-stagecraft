Safety

Three layers, each proven by a test

1 · Injection firewallHidden instructions blocked before any AI reads them: 0 tokens
2 · Action lockCode rejects made-up rooms, overfull rooms, double-booking, keynote moves
3 · Spending limit60k tokens, $0.15, 4 steps per run; stops loops
LoginsSalted scrypt passwords, lockouts and rate limits, security headers; audited and fixed
